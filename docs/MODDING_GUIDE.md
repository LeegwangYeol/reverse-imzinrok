# 임진록 2+ 조선의 반격: 여명 유닛 스탯 바이너리 모딩 가이드 (Modding Guide)

## 1. 개요 (Overview & Engine Architecture)

본 문서는 《임진록 2+ 조선의 반격: 여명》의 메인 실행 바이너리인 `dawn.exe`를 직접 역공학하여 유닛의 **이동 속도(Movement Speed), 체력(HP), 공격력(Attack), 사거리(Range), 공격 딜레이(Delay), 생산 비용(Cost: 쌀/감자/금), 테크트리 요구조건**을 비파괴적으로 수정하는 바이너리 모딩 매뉴얼입니다.

### 1.1 실행 파일 기술 제원
- **타겟 바이너리**: `dawn.exe` (PE32 x86, Little-Endian)
- **컴파일러**: Microsoft Visual C++ 6.0 (`TimeDateStamp = 0x3cd891ac`, 2002-05-08)
- **기준 가상 주소 (ImageBase)**: `0x00400000`
- **고정 파일 크기**: 정확히 `1,032,192` 바이트 (`0x000FC000`)
- **섹션 배치**:
  - `.text`: `0x00401000` ~ `0x004e5000` (Raw: `0x00001000` ~ `0x000e5000`)
  - `.rdata`: `0x004e5000` ~ `0x004f2000`
  - `.data`: `0x004f2000` ~ `0x0055d000`
  - `.rsrc`: `0x0055d000` ~ `0x005fc000`

### 1.2 유닛 초기화 아키텍처
엔진은 게임 구동 시 `.text` 영역(`0x0049bf26` ~ `0x004a2f5c`)에서 111개 유닛/건물/영웅에 대해 순차적으로 `UnitDef::Init(54 args)` 함수(`0x0049baa0`)를 호출합니다. 각 호출은 스택에 54개의 DWORD 인자를 역순(`push`)으로 적재한 후 호출하며, `ecx` 레지스터에는 BSS 전역 배열에 할당된 916바이트 구조체 포인터가 전달됩니다.

## 2. 유닛 스탯 구조체 (`UnitDef`) 및 54개 생성자 인자 매핑

### 2.1 BSS 전역 배열 레이아웃
- **유닛 정의 전역 배열 기저 주소**: `0x009b5228`
- **구조체 크기 (Stride)**: `916` 바이트 (`0x394`)
- **주소 계산 공식**:
  $$\text{Address}(\text{UnitDef}[\text{unit\_id}]) = 0x009b5228 + (\text{unit\_id} \times 916)$$
- **유효 인게임 유닛 ID 범위**: `2` ~ `111` (총 110개 유닛/건물)

## 3. 안전한 바이너리 패칭 원칙 (PE Safety & In-Place Overwriting)

바이너리 수정 시 다음 3가지 절대 규칙을 지키지 않으면 엔진이 실행되지 않거나 메모리 참조 에러(`0xC0000005 ACCESS_VIOLATION`)가 발생합니다.

### 3.1 파일 크기 100% 보존
- `dawn.exe`의 크기는 언제나 정확히 **`1,032,192` 바이트**여야 합니다.
- 바이트의 삽입(Insert)이나 삭제(Delete)는 모든 상대 점프(`E8`, `E9`), IAT 주소, 리소스 오프셋을 어긋나게 하므로 엄격히 금지됩니다.

### 3.2 가상 주소 -> 파일 오프셋 변환 공식
`.text` 섹션의 가상 주소는 디스크 상의 원시 바이트 오프셋과 1:1로 대응됩니다:
$$\text{FileOffset} = \text{VirtualAddress} - 0x00400000$$
*(예: VA `0x0049c090`의 파일 오프셋은 `0x0009c090`입니다.)*

### 3.3 명령어 길이 보존 규칙 (Immediate Encoding)
- x86 아키텍처에서 `push imm8`은 **2바이트 (`6a <val>`)** 이고, `push imm32`는 **5바이트 (`68 <val32>`)** 입니다.
- 원래 2바이트 `push imm8`(`6a 06`)로 인코딩된 스탯을 수정할 때에는 반드시 1바이트 부호 있는 정수 범위(`-128` ~ `127`) 내의 값을 `6a <new_val>` 형태로 제자리 덮어쓰기(In-place Overwrite)해야 합니다.
- 만약 `push imm32`(`68 ...`)로 무리하게 치환하면 뒤따르는 명령어들이 3바이트 밀려나면서 바이너리가 완전히 손상됩니다.

## 4. 실전 스탯 수정 튜토리얼 (Step-by-Step Hands-on)

### 4.1 실습 1: 조선 창병(Swordk) 이동 속도 버프 (6 -> 9)
조선 창병은 게임 내에서 돌격 유닛이지만 기본 속도가 다소 느려 적 기병이나 사선에 쉽게 차단당합니다. 이를 속도 9로 상향 조정합니다.

1. **타겟 유닛 생성자 호출부 특정**:
   - 조선 창병(Unit ID 2)의 `UnitDef::Init` 호출 위치: VA `0x0049c0ca` (파일 오프셋 `0x0009c0ca`)
2. **이동 속도 인자 푸시 명령어 특정**:
   - `arg[29]` (기본 이동 속도): VA `0x0049c090` (파일 오프셋 `0x0009c090`)
     - 원본 바이트: `6a 06` (`push 6`)
   - `arg[30]` (돌격 이동 속도): VA `0x0049c08e` (파일 오프셋 `0x0009c08e`)
     - 원본 바이트: `6a 06` (`push 6`)
3. **바이너리 제자리 패치**:
   - 파일 오프셋 `0x0009c08f`의 바이트를 `0x06`에서 `0x09`로 수정.
   - 파일 오프셋 `0x0009c091`의 바이트를 `0x06`에서 `0x09`로 수정.
4. **검증**:
   - `0x0009c08e` ~ `0x0009c091`의 4바이트가 `6a 09 6a 09`로 기록되었는지 확인.
   - 전후 바이트(`0x0009c08d` 이하 및 `0x0009c092` 이상)가 1바이트도 변경되지 않았음을 확인.

### 4.2 실습 2: 조선 궁수 공격력 상향 (30 -> 35) 및 사거리 증가 (10 -> 11)
1. **타겟 위치**: VA `0x0049c1e4` (조선 궁수 생성자 호출)
2. **공격 사거리 (`arg[25]`)**: VA `0x0049c19e` (`0x0009c19e`)
   - 원본: `6a 0a` (`push 10`) -> 변경: `6a 0b` (`push 11`)
3. **기본 공격력 (`arg[26]`)**: VA `0x0049c19c` (`0x0009c19c`)
   - 원본: `6a 1e` (`push 30`) -> 변경: `6a 23` (`push 35`)

## 5. 자동화 모딩 도구 (`tools/modding/`) CLI 사용법

개발된 모딩 툴킷을 사용하면 수동 헥스 에디팅 없이 CLI 명령어로 즉각 스탯을 조회, 수정, 패치할 수 있습니다.

### 5.1 유닛 카탈로그 데이터셋 내보내기
전체 111개 유닛/건물의 스탯, 가상 주소, 파일 오프셋, 바닐라 대비 여명 변경점을 JSON/YAML로 내보냅니다:
```bash
python -m tools.modding.cli export-catalog --output modified_stats.json
```

### 5.2 유닛 스탯 단일 수정
복사된 `dawn_mod.exe` 바이너리에서 특정 유닛의 이동 속도를 즉시 변경합니다:
```bash
python -m tools.modding.cli modify-stat \
    --binary ./dawn_mod.exe \
    --unit "조선 창병" \
    --field move_speed_base \
    --value 9
```

### 5.3 일괄 패치 적용 및 무결성 검사
수정된 설정 파일(`modified_stats.json`)을 읽어 대상 바이너리에 일괄 적용하고 PE 구조 무결성을 검증합니다:
```bash
python -m tools.modding.cli patch-binary \
    --source C:\src\reverse-imzinrok\YM\dawn\dawn.exe \
    --target ./dawn_patched.exe \
    --config modified_stats.json

python -m tools.modding.cli verify-binary ./dawn_patched.exe
```
